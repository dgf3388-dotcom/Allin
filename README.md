# فوال ألين الطائف — تطبيق ويب (PWA)

موقع مطعم متعدد الصفحات يعمل كتطبيق على أندرويد وآيفون: قائمة طعام، سلة، طلب عبر واتساب، رسوم توصيل حسب المسافة، أصوات، وحفظ بيانات العميل على جهازه.

## الملفات
| الملف | وظيفته |
|---|---|
| `index.html` | التطبيق كاملًا (الصفحات والتصميم والمنطق) |
| `manifest.webmanifest` | بيانات التثبيت كتطبيق (الاسم والألوان والأيقونات) |
| `sw.js` | يتيح فتح التطبيق بدون إنترنت |
| `icons/` | أيقونات التطبيق |
| `.nojekyll` | يمنع GitHub Pages من معالجة الملفات |

## النشر المجاني على GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub (مثلًا `fawal-alain`).
2. ارفع كل محتويات هذا المجلد إلى جذر المستودع (بما فيها مجلد `icons` والملف المخفي `.nojekyll`).
3. من **Settings ← Pages** اختر **Deploy from a branch**، الفرع `main`، المجلد `/ (root)`، ثم احفظ.
4. بعد دقيقة يظهر الرابط: `https://اسم-المستخدم.github.io/fawal-alain/`

الرابط يعمل بـ HTTPS، وهذا مطلوب لتثبيت التطبيق وتحديد الموقع.

## تثبيت التطبيق للعملاء
- **أندرويد (كروم):** زر «ثبّت التطبيق» أو قائمة المتصفح ⋮ ← تثبيت التطبيق.
- **آيفون (سفاري):** زر المشاركة ← إضافة إلى الشاشة الرئيسية.

## التعديلات الشائعة (كلها داخل `index.html`)
ابحث عن هذه الأسماء داخل الملف:
- **الأصناف والأسعار:** المصفوفة `MENU` (الحقول: `c` القسم، `n` الاسم، `p` السعر، `k` السعرات، `d` الوصف). أسعار الأطباق اليمنية الحالية تقديرية، عدّلها.
- **أقسام القائمة:** مصفوفة الأقسام داخل دالة `tabs`.
- **رقم الطلبات (واتساب):** ابحث عن `966537161468` وغيّره في كل موضع.
- **موقع المطعم:** المتغير `REST` (خط العرض والطول).
- **شرائح رسوم التوصيل:** المتغير `TIERS`، كل شريحة `[أقصى مسافة بالكم، الرسوم]`، وما بعد آخر شريحة خارج النطاق.
- **الألوان:** متغيرات `:root` في أعلى الملف.

## عند تغيير الملفات بعد النشر
غيّر قيمة `CACHE` في `sw.js` (مثلًا `fawal-alain-v2`) كي يحصل العملاء على النسخة الجديدة.

## ملاحظات
- الطلبات تصل المطعم عبر واتساب، ولا يوجد خادم أو لوحة طلبات.
- بيانات العميل وطلباته السابقة تُحفظ على جهازه فقط.
- الصوت الترحيبي يستخدم صوت الجهاز العربي المدمج.
